## About

**Projeto 1 Disciplina:** Programação Web Full Stack<br><br>
App React + TypeScript que permite inserir a estrutura molecular (SMILES) de um composto e obter uma predição de toxicidade clínica via modelo MAMMAL (IBM Research).

## API

[Cure Cancer With AI](https://curecancerwithai.com)

- `POST /api/v1/mammal/clintox` - predição de toxicidade a partir do SMILES
- `GET /api/v1/search?keyword=...` - busca de compostos/itens relacionados

## Hook / Funcionalidade React

`forwardRef` - usado no componente de input do formulário de SMILES

## Biblioteca Externa

`react-hook-form` - usada pro formulário de SMILES (validação e gerenciamento de estado dos campos)
