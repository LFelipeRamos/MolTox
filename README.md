## About

**Projeto 1 Disciplina:** Programação Web Full Stack<br><br>
App React + TypeScript que permite inserir a estrutura molecular (SMILES) de um composto e obter uma predição de toxicidade clínica via modelo MAMMAL (IBM Research).
